## Projects

### Project 01 - SSH Brute Force Detection & Response
- Investigated SSH brute-force attempts using '/var/log/auth.log'
- Automated analysis with a Bash summary script
- Contained attacks using Fail2Ban and verified the ban
- Incident report mapped to MITRE ATT&CK (T1110)

### Project 02 - Phishing Email Investigation
- Analyzed phishing email headers to identify spoofing attempts
- Interpreted SPF, DKIM, and DMARC authentication failures
- Extracted indicators of compromise (IOCs)
- Mapped findings to MITRE ATT&CK (T1566 - Phishing)

### Project 03 - Python SSH Log Parser
- Built a Python script to parse Linux authentication logs
- Detected repeated failed SSH login attempts
- Aggregated activity by source IP and username
- Demonstrated automation for SOC detection workflows
