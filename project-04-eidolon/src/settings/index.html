Eidolon — Settings

Protection features
Block Trackers
Block network requests to known tracking and advertising domains using declarative rules.
Spoof Canvas Fingerprint
Add imperceptible per-session noise to canvas output so each session produces a unique fingerprint.
Block WebRTC IP Leak
Force relay-only ICE transport on WebRTC connections to prevent your real IP from being exposed.
Note: Canvas and WebRTC changes take effect on the next page load for already-open tabs. Tracker blocking takes effect immediately.
