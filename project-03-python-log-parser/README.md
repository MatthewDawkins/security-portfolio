# Project 03 — Python SSH Log Parser

## Overview
This project implements a Python-based log parser to analyze Linux SSH authentication logs. The script identifies repeated failed login attempts, groups activity by source IP and username, and outputs a summarized report.

## Goals
- Parse `/var/log/auth.log`
- Detect failed SSH authentication attempts
- Aggregate activity by IP address and username
- Automate brute-force detection logic
- Demonstrate Python scripting for SOC workflows

## Artifacts
- `ssh_log_parser.py` — Python script for SSH log analysis

- Python scripting
- Log parsing and pattern matching
- Security automation
- Brute-force detection logic
